# ربات ارسال پیام گروهی تلگرام

## معرفی
این یک ربات تلگرامی است که برای ارسال پیام‌های تبلیغاتی یا اطلاع‌رسانی به صورت زمان‌بندی شده به یک گروه مشخص طراحی شده است. ادمین ربات می‌تواند گروه هدف، محتوای پیام (متن یا تصویر) و زمان‌بندی ارسال را به صورت پویا و از طریق دستورات داخل خود ربات تنظیم کند.

## قابلیت‌ها
- **ارسال پیام در گروه:** ارسال پیام تنظیم شده در گروه هدف.
- **پشتیبانی از متن و تصویر:** قابلیت تنظیم پیام به صورت متنی یا یک تصویر همراه با کپشن.
- **تنظیمات پویا:** ادمین می‌تواند تمام تنظیمات را با دستورات داخل ربات تغییر دهد.
- **زمان‌بندی خودکار:** قابلیت تنظیم زمان‌بندی ارسال پیام با استفاده از عبارات `cron`.
- **ارسال فوری:** امکان ارسال پیام در لحظه برای تست.
- **پیام خوش‌آمدگویی:** ارسال پیام خوش‌آمدگویی به اعضای جدید به صورت خصوصی (DM).
- **قابلیت انصراف (Opt-Out):** کاربران می‌توانند از دریافت پیام‌های مستقیم آینده (مانند پیام خوش‌آمدگویی) انصراف دهند.
- **امن و قابل اطمینان:** جلوگیری از ارسال پیام‌های اسپم و مدیریت خطاها.

## پیش‌نیازها
- پایتون نسخه 3.8 یا بالاتر
- `pip` برای نصب کتابخانه‌ها

## مراحل راه‌اندازی

**۱. دریافت کد**
کد پروژه را دانلود کرده و در یک پوشه قرار دهید.

**۲. ایجاد محیط مجازی (توصیه می‌شود)**
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

**۳. نصب وابستگی‌ها**
فایل `requirements.txt` تمام کتابخانه‌های مورد نیاز را در خود دارد. با دستور زیر آن‌ها را نصب کنید:
```bash
pip install -r telegram_bot/requirements.txt
```

**۴. دریافت توکن ربات**
- به ربات [@BotFather](https://t.me/BotFather) در تلگرام بروید.
- یک ربات جدید با دستور `/newbot` بسازید.
- پس از انتخاب نام و یوزرنیم برای ربات، `BotFather` یک توکن به شما می‌دهد. این توکن را کپی کنید.

**۵. تنظیم متغیر محیطی**
توکن ربات خود را به عنوان یک متغیر محیطی (Environment Variable) با نام `TELEGRAM_TOKEN` تنظیم کنید.
- **در لینوکس/مک:**
  ```bash
  export TELEGRAM_TOKEN="YOUR_TELEGRAM_TOKEN"
  ```
- **در ویندوز (Command Prompt):**
  ```bash
  set TELEGRAM_TOKEN="YOUR_TELEGRAM_TOKEN"
  ```
**نکته:** برای استفاده دائمی، این متغیر را در فایل پروفایل شل خود (`.bashrc`, `.zshrc`) یا در تنظیمات سیستم ویندوز قرار دهید.

**۶. تنظیم شناسه کاربری ادمین**
- به ربات [@userinfobot](https://t.me/userinfobot) بروید و دکمه `Start` را بزنید. این ربات شناسه عددی کاربری شما (User ID) را نمایش می‌دهد.
- فایل `telegram_bot/main.py` را باز کرده و در خط زیر، شناسه کاربری خود را جایگزین `123456789` کنید:
  ```python
  ADMIN_USER_ID = 123456789  # !!! شناسه کاربری ادمین را اینجا قرار دهید
  ```

## اجرای ربات
پس از انجام تمام مراحل بالا، ربات را با دستور زیر اجرا کنید:
```bash
python telegram_bot/main.py
```
اگر همه چیز به درستی تنظیم شده باشد، پیام `ربات در حال اجرا است...` را در ترمینال خود مشاهده خواهید کرد.

## دستورات ربات (مخصوص ادمین)
برای استفاده از این دستورات، به ربات خود پیام دهید.

- `/start`: شروع تعامل با ربات.
- `/help`: نمایش پیام راهنمای دستورات.
- `/status`: نمایش وضعیت فعلی تنظیمات ربات (گروه هدف، پیام تنظیم شده و زمان‌بندی).
- `/setgroup <GROUP_ID>`: تنظیم گروهی که پیام باید در آن ارسال شود.
  - **نکته:** برای پیدا کردن `GROUP_ID`، ربات خود را به گروه مورد نظر اضافه کرده و آن را ادمین کنید. سپس یک پیام در گروه ارسال کنید. با مراجعه به آدرس `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates` می‌توانید شناسه گروه را (یک عدد منفی و طولانی) پیدا کنید.
- `/setmessage`: شروع فرآیند تنظیم پیام. پس از ارسال این دستور، ربات از شما می‌خواهد که پیام مورد نظر خود را (متن یا یک عکس با کپشن) ارسال کنید.
- `/setschedule <CRON_EXPRESSION>`: تنظیم زمان‌بندی ارسال خودکار.
  - از فرمت استاندارد `cron` استفاده می‌کند. مثال: `0 9 * * *` برای ارسال هر روز ساعت ۹ صبح.
  - برای حذف زمان‌بندی، از دستور `/setschedule none` استفاده کنید.
- `/sendnow`: ارسال فوری پیام تنظیم شده برای تست.
- `/cancel`: لغو عملیات در حال انجام (مانند تنظیم پیام).

## نکات مهم
- **ادمین بودن ربات:** ربات باید در گروه هدف عضو و دارای دسترسی ادمین (حداقل برای ارسال پیام) باشد.
- **حریم خصوصی گروه‌ها:** ربات باید تنظیمات حریم خصوصی (Privacy Mode) آن در `BotFather` غیرفعال باشد تا بتواند پیام‌ها را در گروه بخواند (برای پیدا کردن شناسه گروه).
- **زمان‌بندی:** زمان‌بندی بر اساس منطقه زمانی UTC تنظیم شده است.
